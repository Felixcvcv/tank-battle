# 坦克大战 · Battle City

经典红白机《坦克大战》的网页复刻版 —— **单文件 HTML5 Canvas 实现，零依赖、零构建，双击即玩。**

保护你下方的老鹰基地，消灭全部 20 辆敌军坦克，一路打到第 4 关。

---

## 在线试玩

开启 GitHub Pages 后即可直接游玩：

```

```

## 游戏内容

**地形**
- 🧱 **砖墙** —— 可被子弹逐块打穿，能打出仅容一辆坦克通过的缺口
- ⬜ **钢板** —— 普通子弹打不穿，需要三级火力（钢弹）
- 🌊 **水域** —— 坦克无法通过，子弹可以飞越
- 🌳 **树林** —— 坦克和子弹都能穿过，但会遮挡视线（绘制在坦克之上）
- 🧊 **冰面** —— 松开方向键后仍会向前滑行

**敌军**（四种，性能各不相同）

| 类型 | 生命 | 速度 | 子弹速度 | 分值 |
| --- | --- | --- | --- | --- |
| 普通 | 1 | 慢 | 普通 | 100 |
| 快速 | 1 | 快 | 普通 | 200 |
| 炮击 | 1 | 中 | 快 | 300 |
| 装甲 | 4 | 慢 | 普通 | 400 |

装甲坦克每中一弹会变色（绿 → 黄 → 橙 → 红），是最难缠的对手。

**道具**（击毁每关第 4、11、18 辆敌军时掉落）

| 道具 | 效果 |
| --- | --- |
| ⭐ 星星 | 火力升级（三级可发射击穿钢板的钢弹，二级起双发） |
| 💣 手雷 | 立即炸毁场上全部敌军 |
| ⛑ 头盔 | 12 秒无敌护盾 |
| ⛏ 铁锹 | 基地周围的砖墙临时变为钢板，20 秒后复原 |
| 🚩 坦克 | 生命 +1 |
| ⏱ 时钟 | 冻结全部敌军 10 秒 |

**其他规则**
- 每关 20 辆敌军，同时在场数量随关卡提升（4 → 5 → 6）
- 玩家 3 条命，阵亡后火力等级重置（与原作一致）
- 基地被击毁或被敌军攻入基地即告失败
- 最高分通过 `localStorage` 持久保存

## 技术实现

整个游戏就是一个 `index.html`，约 1700 行，没有外部图片、字体、音频或第三方库。

- **像素美术**：所有坦克、地形、老鹰、道具、爆炸都用 Canvas 的 `fillRect` 按 16×16 的像素格程序化绘制，坦克按 4 个朝向旋转绘制。
- **音效**：用 Web Audio API 现场合成 —— 方波做射击与拾取音，噪声爆破做爆炸，锯齿波低鸣做引擎声。无需任何音频文件。
- **坐标系统**：以 16px 的「半格」为地形最小单位，战场 26×26 个半格；坦克占 1 格（32px），与初代的尺寸比例一致。
- **手感**：坦克移动是像素级平滑的，转向时会自动向最近的半格对齐，因此可以顺畅地钻进自己打出的缺口 —— 这是还原原作手感的关键。
- **主循环**：`requestAnimationFrame` 驱动固定 60Hz 步进（累加器 + 补帧上限），子弹分步推进以避免高速穿透。
- **健壮性**：`render()` 中的 `ctx.save()`/`ctx.restore()` 用 `try/finally` 保证配对 —— 否则一次绘制异常会把裁剪区永久留在 Canvas 上下文里，画面将再也无法恢复。
